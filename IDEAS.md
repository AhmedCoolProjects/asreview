## Ideas

### For Each New Project (DONE)

1. When we upload a new project from a .ris file for example, we need to be able to add a "description" field to the project that describes how we got this .ris file, what search query we used, what source titles we were limited to, what date range and what platform we used to get this .ris file. This description should be saved in the project metadata.

### For Global Tags (DONE)

1. We need to be able to create Global Tags "outside" of a specific project. This means that we can create tags that are available to all projects. We may add a button on the left sidebar called "Global" which it does contain the Tags dialog that we already have in the customization settings of each project. We can just use that dialog for the Global Tags.
